# DeviceHelper

The project maintainer has a copy of the Skydroid DeviceHelper/update-tool package for analysis.

The executable and bundled libraries are not included in this initial repository scaffold. Do not upload vendor binaries until redistribution rights are clear.

Research notes may document version metadata, observed behaviour, supported hardware profiles, serial/USB interfaces, and update protocol findings. Do not assume the updater is universal across S10-family devices without testing and evidence.
