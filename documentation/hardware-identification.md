# Hardware identification

Before comparing or flashing firmware, record as much of the following as is available:

- Exact product/model name from the device label and system information
- Hardware revision and board identifiers
- Current firmware version
- Relevant radio/display/control-board identifiers
- Update-tool version and operating system used
- Photographs of labels and connector/board markings, with personal serials redacted before public posting

A shared product family or updater does not prove that firmware images are interchangeable. Treat unknown model associations as unverified.
