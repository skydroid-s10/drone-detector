# Firmware history

## S10G2

- **v3.0** — Reported by the project maintainer as the latest official release available for the S10G2 device under investigation, and the known-working baseline for that device.
- Original firmware binary, source URL/acquisition details, exact hardware association, file size, and SHA-256 should be recorded before archiving or analysis.
- No reconstructed or modified image is considered flash-ready merely because it derives from the official image.

## Other models

Do not infer compatibility between S10-family models from similar names or a shared updater. Record each model and hardware revision separately.
