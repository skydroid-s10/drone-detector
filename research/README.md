# Research notes

Use this area for reproducible static-analysis notes, update-protocol observations, and reverse-engineering hypotheses.

For each finding, record:
- Artifact name and SHA-256
- Tool and version used
- Offset/address and relevant context
- Observation and supporting evidence
- Confidence: verified, strong evidence, or hypothesis
- Independent cross-checks and unresolved questions

Keep raw observations separate from interpretation. Do not publish secrets, credentials, private device identifiers, or binaries without appropriate redistribution rights.
