## Required metadata for any permitted archive release

Before adding a binary, record:

- Exact original filename and byte size.
- SHA-256 calculated from the exact file being archived.
- Original download URL or transfer source, date obtained, and any accompanying vendor release notes.
- Model and hardware revision to which it was supplied or tested.
- Firmware version shown by the updater/device, distinguishing observed facts from filename claims.
- Whether the file is original, modified, reconstructed, or merely repackaged.
- Redistribution permission or licence basis.

A hash identifies a byte-for-byte artifact; it does not prove vendor authenticity, safety, or compatibility.
