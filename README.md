# Skydroid S10 Firmware Archive & Research

Independent archive and research project for Skydroid S10/S10G2 firmware, update tooling, hardware identification, and protocol research.

## Project principles

- Preserve original vendor files unchanged and record where and when each file was obtained.
- Record the target model, hardware revision (when known), firmware version, and SHA-256 checksum for every archived artifact.
- Keep original firmware, research notes, tools, and any modified firmware clearly separated.
- Do not describe reconstructed or modified firmware as flash-ready until its integrity, compatibility, and any required authentication or packaging checks have been established.
- Do not publish vendor binaries unless redistribution rights are clear; where necessary, publish metadata, hashes, documentation, and legitimate source links instead.

## Current baseline

The project is investigating the official Skydroid S10G2 v3.0 firmware reported by the project maintainer as the latest available release for their device. Exact hardware/model association and file hashes should be recorded alongside the original file before further analysis.

## Research areas

- Model and hardware identification
- Firmware provenance and checksums
- Update-tool behaviour and update protocol documentation
- Static analysis and reverse engineering
- Safe, reproducible research workflows

## Safety

Do not flash reconstructed or modified images onto a device unless compatibility and integrity have been independently verified. Keep a verified original firmware copy and a recovery plan.
