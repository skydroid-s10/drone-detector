# Contributing

Please preserve evidence and provenance.

## Rules

1. Never replace an original binary with a modified binary under the same filename.
2. Never label an unverified firmware image as compatible.
3. Include SHA-256 for archived binaries.
4. Record the exact source and acquisition date where possible.
5. Clearly label reverse-engineering conclusions as verified, strong evidence, or hypothesis.
6. Do not test unknown firmware on hardware you cannot afford to lose.
7. Keep experimental/custom firmware separate from untouched manufacturer firmware.
